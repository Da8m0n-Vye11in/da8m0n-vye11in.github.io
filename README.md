#   Tessera

English version: [README_EN.md](README_EN.md)

一个实验性的、将 Minecraft 复刻到网页上的开源项目。

> ⚠️ **早期测试阶段**
> 项目目前处于基础内容开发阶段，功能不断迭代，存档格式和 API 随时可能变动。

## 🎯 项目目标

在Pre阶段，用纯前端技术（HTML + JavaScript + WebGL）在浏览器中还原 Minecraft 的核心体验：
方块世界、第一人称探索、挖掘与建造、昼夜与天气、光照与生物群系。

## 🛠️ 技术栈

- **Three.js** — 3D 渲染
- **原生 JavaScript** — 游戏逻辑
- **WebGL** — GPU 加速
- **localStorage** — 本地存档
- **纯前端** — 无需后端，静态托管即可运行

## ✨ 目前实现的功能

### 世界
- 无限世界（按区块动态加载/卸载）
- 程序化地形生成（噪声驱动）
- 生物群系：森林 / 平原 / 沙漠
- 洞穴系统（3D 噪声）
- 树木生成（原木 + 树叶）
- 昼夜循环（40 分钟一天）
- 天气系统：晴 / 雨 / 雪 / 沙尘暴

### 玩法
- 第一人称视角 + 触屏摇杆
- 挖掘 / 放置方块
- 背包系统 + 物品栏
- 2x2合成系统（目前只能用原木来合成木板）
- 方块掉落物 + 自动拾取
- 沙子重力下落（无动画）
- 飞行模式
- 旁观模式（X光透视，目前存在问题，修复中）

### 光照
- Minecraft 风格体素光照系统
- 天空光垂直传播 + 水平扩散
- 火把点光源
- 方块遮挡导致亮度分级

### 存档
- 自动保存到浏览器 localStorage
- 导出 / 导入 `.json` 存档文件

## 📱 运行方式

### 在线游玩
访问 GitHub Pages：https://da8m0n-vye11in.github.io

### 本地运行
克隆仓库后，用任意 HTTP 服务器托管根目录（不要用 `file://` 直接打开）：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000

.
├── index.html      # 主页面 + 游戏逻辑
└── lighting.js     # 体素光照引擎
└── lang.js         #多语言实现
```

# 操作方式
- 移动 左下角虚拟摇杆
- 转视角 屏幕空白区域滑动
- 放置方块 单击屏幕
- 破坏方块 长按屏幕 0.45 秒
- 跳跃 右下角绿色按钮
- 切换方块 底部物品栏
- 背包 / 合成 物品栏左侧 ⋯ 按钮
- 设置 右上角 ⚙️
- 存档 / 读档 右上角 💾 / 📂
